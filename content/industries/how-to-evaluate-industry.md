## 一、先排除“看起来很美”的行业

有三类行业，新手最容易误判：

| 类型 | 表面特征 | 真实问题 |
| --- | --- | --- |
| 高增长风口 | 媒体持续报道、融资频繁 | 竞争激烈、获客成本高、变化快 |
| 高毛利生意 | 毛利率 70% 以上 | 获客成本高、复购低、需求不稳定 |
| 低门槛加盟 | 投入小、总部承诺多 | 同质化严重、总部抽成、退出困难 |

判断一个行业值不值得进，不是看它“有多热”，而是看它**是否适合你，且能持续**。

## 二、五维评估框架

| 维度 | 关键问题 | 判断标准 |
| --- | --- | --- |
| 需求稳定性 | 需求会持续发生吗？ | 频率高、非可选、受经济周期影响小 |
| 竞争结构 | 市场是分散还是集中？ | 分散市场看效率，集中市场看差异化 |
| 成本结构 | 固定成本占比多高？ | 低于 40% 更安全 |
| 监管与合规 | 需要什么资质？ | 门槛适中，且你能满足 |
| 个人匹配度 | 你的技能与资源是否匹配？ | 至少有一项明显优势 |

五个维度不需要全部满分，但**不能有两项明显不合格**。

### 需求稳定性

问三个问题：

1. 这个需求是“必须有”还是“可以有”？
2. 经济下行时，客户会先砍掉它吗？
3. 需求频率是每年一次，还是每月一次？

频率决定获客成本能否摊薄。一年一次的需求，获客成本几乎无法回收。

### 竞争结构

| 结构 | 特征 | 机会 |
| --- | --- | --- |
| 高度分散 | 大量个体户、无强势品牌 | 用标准化与效率做整合 |
| 区域集中 | 本地有几家强势商家 | 用差异化切细分客群 |
| 高度集中 | 全国性品牌主导 | 只能做配套或极小众 |

分散市场看起来“谁都能做”，但对运营效率要求更高；集中市场看起来“没机会”，但细分需求往往被忽略。

### 成本结构

用一张表估算：

| 项目 | 金额 | 类型 |
| --- | --- | --- |
| 房租 | | 固定 |
| 人工底薪 | | 固定 |
| 设备折旧 | | 固定 |
| 材料 | | 变动 |
| 平台佣金 | | 变动 |

固定成本占预计收入的比例超过 40%，意味着淡季风险很高。

### 监管与合规

需要提前确认：营业执照经营范围、行业许可证、消防与环保要求、用工与社保、税务申报方式。

**合规成本不是“以后再说”的事，它会直接影响你的定价与利润。**

### 个人匹配度

| 你的优势 | 适合的行业 |
| --- | --- |
| 有行业经验 | 需要专业判断的服务 |
| 有客户资源 | B 端服务、渠道生意 |
| 有内容能力 | 知识服务、内容电商 |
| 有供应链资源 | 零售、批发、定制 |
| 只有时间与执行力 | 标准化服务、本地生意 |

如果一项优势都没有，先积累优势，而不是先创业。

## 三、三类数据交叉验证

不要只看行业报告。报告给的是平均值，而小生意活在具体场景里。

| 数据类型 | 来源 | 能回答什么 |
| --- | --- | --- |
| 公开统计 | 统计局、市场监管总局 | 行业规模、增速、企业数量 |
| 平台数据 | 电商/本地生活平台的销量与价格 | 真实成交价格带、竞争密度 |
| 实地访谈 | 同行、供应商、目标客户 | 真实利润、客流、痛点 |

三者交叉验证，能避免两类错误：

- **只看报告**：高估市场，低估竞争。
- **只看同行**：模仿别人的做法，却不知道对方的成本结构。

## 四、实地调研的五个问题

找到 3–5 位同行，问这五个问题（不必一次问完）：

1. 一天大概多少单？旺季淡季差多少？
2. 房租和人工占营业额多少？
3. 客户主要从哪来？哪个渠道最有效？
4. 最难的是什么？最容易被投诉的是什么？
5. 如果重来一次，你会改什么？

同行未必说真话，但**多个样本的重复模式**很有价值。

:::risk 四个行业选择的常见错误
1. **只看毛利率，不看获客成本**：高毛利可能被高获客成本吃光。
2. **只看成功案例，不看失败样本**：幸存者偏差会让你低估风险。
3. **忽略合规成本**：资质、消防、环保、社保都是真实支出。
4. **低估退出成本**：押金、装修、设备、合同违约金。
:::

:::action 用四周完成一次行业评估
第 1 周：收集公开数据，列出 3 个候选行业。
第 2 周：每个行业找 3 位同行访谈，记录真实数字。
第 3 周：估算启动投入、固定成本、客单价与平衡点。
第 4 周：用五维框架打分，选一个行业做小规模测试。
:::

## 五、结论

判断一个行业是否值得进入，最终要回答三个问题：

1. 需求会持续发生吗？
2. 我能在这个竞争结构里找到位置吗？
3. 如果失败，我能承受退出成本吗？

三个问题都有明确答案，才值得投入。

一句话总结：**好行业不等于好生意，适合你的行业才是。**
