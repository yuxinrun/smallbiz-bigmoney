## A. 案例概况

这是一个个人经营的二手 3C 回收与转卖模型：从个人卖家、写字楼、维修店收货，验机、清洁、简单维修后，通过二手平台或私域转卖。主营手机、平板与笔记本，客单价 1,000–3,000 元。

| 项目 | 说明 |
| --- | --- |
| 所属行业 | 二手商品流通 / 3C 零售 |
| 商业形态 | 个人收货转卖，轻门店或纯线上 |
| 目标客户 | 预算有限的学生、备用机用户、下沉市场 |
| 主要品类 | 手机、平板、笔记本 |
| 收入结构 | 收售价差为主，少量维修与配件 |
| 研究口径 | 业态型案例，价差为公开报价区间，经营数据为示例测算 |

## B. 商业机会

二手 3C 的需求来自“性能过剩 + 预算约束”：新机越来越贵，旧机性能仍然够用。供给则来自换机周期与闲置处理。

客户为什么买二手？核心是**同样的预算买到更高配置**。客户为什么卖二手？核心是**比闲置更有价值**。

这门生意的竞争不在“有没有货”，而在**收货价格、验机能力与出货速度**。收贵了没利润，收便宜了没货；验机漏了要赔，出货慢了要降价。

## C. 商业模式

价值链：收货 → 验机 → 清洁/维修 → 定价 → 上架 → 成交 → 售后。

利润来自三段：

- **收售价差**：主要来源，单台 150–350 元。
- **维修增值**：换电池、换屏、清灰，毛利更高但需要手艺。
- **配件与延保**：提高客单价，但会增加售后。

真正的经营指标不是毛利率，而是**资金周转次数**。8 万元本金，一个月周转一次，一年可以做 12 次；如果压货两个月，一年只能做 6 次，回报直接减半。

**关键结论**：单台净赚约 100 元，月销 70 台才有 7,000 元净利。这不是“暴利行业”，而是一门**用资金周转换回报**的辛苦生意。

## E. 获客方法

- **上门/到店回收**：在写字楼、维修店、小区设固定回收点，靠“当场验机、当场付款”建立信任。
- **平台回收**：流量大但压价狠，适合走量，不适合积累客户。
- **私域转卖**：把买过的客户加微信，复购与转介绍成本最低。
- **内容获客**：发布验机知识、避坑指南，比单纯发商品更容易建立专业形象。

收货端的获客成本常被忽略：一次上门收空的油费与时间，就是成本。

## F. 经营流程

| 环节 | 关键动作 | 控制点 |
| --- | --- | --- |
| 收货 | 查序列号、验功能、测电池 | 拒绝来源不明设备 |
| 验机 | 屏幕、摄像头、主板、进水痕迹 | 逐项记录，拍照存档 |
| 整备 | 清洁、换电池、刷机 | 成本超过毛利 40% 就放弃 |
| 定价 | 参考同款成交价，留出售后空间 | 不按收货价“加固定利润” |
| 出货 | 描述瑕疵、拍摄实图 | 减少退货与纠纷 |
| 售后 | 7–30 天保修 | 预留 2%–3% 售后准备金 |

最大的运营难点是**验机与定价**：同一型号不同成色，价差可能超过 300 元；一次看走眼，几台利润就没了。

## G. 复制可行性

最低条件：

1. 有 5–8 万元周转资金，且能承受 10%–20% 的库存贬值。
2. 具备验机能力，或有一个可靠的维修师傅合作。
3. 能接受频繁沟通、议价与售后。

可复制的是验机流程与定价方法；不可复制的是**货源渠道与信誉积累**。老回收商能收到好货，是因为卖家相信他不会压价、不会调包。

:::action 先用 20 台验证
不要一次压 50 台。先用 20 台跑完整循环，记录：收货价、整备成本、上架天数、成交价、退货率。如果平均周转超过 35 天，或退货率超过 8%，说明定价或验机有问题。
:::

## H. 风险与失败原因

:::risk 四类风险
1. **价格下跌**：新机降价或新款发布，旧机库存可能一夜贬值 5%–10%。
2. **验机失误**：进水、暗病、组装机，一次赔付可能吃掉数台利润。
3. **来源风险**：收到赃物会带来法律风险，必须实名登记并保留凭证。
4. **售后纠纷**：二手商品瑕疵争议多，没有清晰描述与保修规则很容易被投诉。
:::

## J. 案例研究结论

二手 3C 是一门**资金驱动、周转为王**的生意。它的毛利率不高，但现金流快；它的门槛不在资金，而在验机与信誉。

如果只能记住一个公式，那应该是：**年化回报 ≈ 单台净利 × 年周转次数 ÷ 投入本金**。提高周转次数，比提高单台毛利更现实。
