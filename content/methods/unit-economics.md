## 一、为什么“我觉得挺赚钱”是最危险的状态

很多小生意老板年底一算账，发现账上没钱，但每天都很忙。

原因通常不是“没生意”，而是**从来没算过单笔生意赚多少**。营业额是虚荣指标，成本是分散的，中间的差额就变成了“感觉”。

算清单客经济，只需要回答四个问题：

1. 一个客户付我多少钱？（客单价）
2. 服务这一个客户，我要额外花多少钱？（变动成本）
3. 为了得到这个客户，我花了多少钱？（获客成本）
4. 这个客户会来几次？（复购次数）

四个数字相乘相减，就是这门生意的真实盈利能力。

## 二、先把成本分成两类

| 类型 | 定义 | 例子 | 特点 |
| --- | --- | --- | --- |
| 固定成本 | 不管有没有生意都要付 | 房租、底薪、软件订阅、执照年费 | 单量越大，单均分摊越低 |
| 变动成本 | 每做一单才发生 | 材料、耗材、平台佣金、计件人工、物流 | 与单量同比例变化 |

分不清这两类，就会出现经典误判：

- 把房租算进“每单成本”，于是以为多接单能摊薄，却忽略了产能上限。
- 把一次性设备投入算进月度成本，于是以为永远不赚钱。
- 忘记平台佣金与支付手续费，于是毛利率虚高 5–10 个百分点。

## 三、单客账单：一步一步算

假设一门上门服务生意：

- 客单价：300 元
- 单次材料与耗材：40 元
- 平台抽佣 10%：30 元
- 计件人工：80 元
- 交通：20 元

**变动成本合计 170 元，单客毛利 130 元，毛利率 43.3%。**

接着算固定成本分摊。月固定支出 12,000 元（房租仓储 3,000 + 底薪 7,000 + 软件与保险 2,000），月均 100 单，则：

**单均固定成本分摊 120 元，单客净利 10 元。**

看到问题了吗？毛利率 43% 听起来不错，但净利只剩 3.3%。这家店几乎是在给房东和平台打工。

如果把客单价提到 360 元（服务内容不变），单客净利立刻变成 70 元——**净利增长 7 倍，而收入只增长 20%**。

## 四、回本周期怎么算

回本周期的正确算法是：

> 回本周期 = 初始投入 ÷ 月净现金流

而不是“初始投入 ÷ 月营业额”。

一家投入 25 万元的小店，如果月营业额 15 万元、净利率 8%，月净利是 1.2 万元，回本约 21 个月。如果净利率只有 3%，回本要 55 个月——**四年多**，这期间任何一次租金上涨或设备故障都会让计划失效。

所以看回本周期时，必须同时问三个问题：

1. 这个净利率，是最好月份还是平均水平？
2. 有没有把老板自己的工资算进成本？
3. 设备折旧与装修摊销有没有计入？

:::risk 四个最常见的算错方式
1. **不给自己发工资**：老板的人力成本被隐藏，账面利润虚高。
2. **只算毛利不算净利**：忽略房租、人工、平台佣金等固定支出。
3. **用营业额算回本**：营业额不是现金，回本要用净现金流。
4. **按最好月份推算全年**：旺季数据不能代表平均值，淡季才是生死线。
:::

## 五、什么情况下不该扩张

扩张（加人、加店、加品）的前提是：**新增这一单的边际毛利为正，且不会拖垮交付质量**。

三种不该扩张的信号：

| 信号 | 含义 | 应该做什么 |
| --- | --- | --- |
| 单客净利已经在盈亏线附近 | 规模越大，亏损越多 | 先涨价或降成本 |
| 交付质量随单量下降 | 复购率会跟着掉 | 先补流程与人力 |
| 获客成本持续上升 | 渠道已经饱和 | 先换渠道，不要加预算 |

## 六、一张可以每周填的表

把下面这张表贴在收银台或记账软件里，每周填一次：

| 指标 | 本周 | 上周 | 变化 |
| --- | --- | --- | --- |
| 订单数 | | | |
| 营业额 | | | |
| 变动成本 | | | |
| 单客毛利 | | | |
| 新增客户数 | | | |
| 获客支出 | | | |
| 复购客户数 | | | |

四周之后，你会看到两个关键趋势：**单客毛利是否稳定**、**复购占比是否上升**。这两个趋势比营业额更能预测你明年还在不在。

:::action 今晚花 40 分钟算一遍
1. 列出你最近一个月的全部支出，逐项标“固定”或“变动”。
2. 用营业额 ÷ 订单数，算出真实客单价。
3. 用（营业额 − 变动成本）÷ 订单数，算出单客毛利。
4. 用固定成本 ÷ 订单数，算出单均分摊。
5. 两者相减，得到单客净利。如果低于客单价的 10%，本周就做一次定价或成本调整。
:::

## 七、结论

单客经济模型的价值，不是给你一个精确到元的数字，而是给你一个**判断方向**：

- 是价格太低，还是成本太高？
- 是获客太贵，还是复购太少？
- 是该扩张，还是该收缩？

一门生意能不能做大，取决于它能不能在**每一单上都赚到钱**。靠规模掩盖单笔亏损的模式，最终都需要外部资金来填——而小生意通常没有这笔钱。

一句话总结：**先让一单赚钱，再让一百单赚钱。**
